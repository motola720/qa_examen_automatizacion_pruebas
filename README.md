# qa_examen_automatizacion_pruebas

Proyecto Java con Maven y JUnit 5 para practicar automatizacion de pruebas y CI con Jenkins.

## Requisitos
- Java 17
- Maven
- Git
- Jenkins (plugins: Pipeline, Git, JUnit) y Maven M3 configurado

## Ejecutar pruebas en local
```bat
mvn clean test
